\# Contributing



Contributions are welcome — corrections to control mappings, new evidence scripts,

or additional framework coverage.



\## Ground rules



\- No real tenant data, screenshots, or credentials in any PR — synthetic data only

\- Cite the source clause/article when adding or changing a control mapping

\- Keep scripts read-only — this toolkit pulls evidence, it does not modify tenant config



\## How to contribute



1\. Fork the repo

2\. Create a branch for your change

3\. Open a pull request describing what changed and why
